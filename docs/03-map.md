# 分布地图：全国、省份与时间回放

> 对应页面：<https://www.aqistudy.cn/map>

分布地图把「一城一数」摊成一张可以回放的图：全国 389 座城市按 AQI（或任一项污染物）着色，拖时间轴就能看到污染带怎么推进。

## 一、顶部这一行的顺序

从左到右依次是：

**视图**（全国 / 省份）→ **分辨率**（小时 / 日 / 月）→ **快捷范围** → **历史日期** → **起止时间** → **查询历史** → **回到实时**

这个顺序是「先定看什么，再定看哪一段」：视图决定了地图的粒度（一城一点还是一省一色），分辨率决定了时间轴上每一帧代表多长，最后才是具体的时段。

「回到实时」回到当前最新时次，任何时候点一下都能从历史跳回来。

## 二、左侧时次列表 = 时间轴

左侧列出当前范围内的每一帧，点哪一帧地图就换到那个时次。上面的「自动播放」按顺序逐帧推进，看沙尘或雾霾的推进过程像看视频一样。

两处细节：

- **每一帧对应明确的时次**，图上标着「某日某时 · AQI 分布 · N 个城市」，不会出现「这是几点数据」说不清的情况。
- **帧上的城市数是有效城市数**。缺测城市不参与着色，也不参与插值。

## 三、右侧图层面板

面板分两组：

| 分组 | 可选字段 |
| --- | --- |
| **空气质量** | AQI、PM₂.₅、PM₁₀、SO₂、NO₂、CO、O₃、O₃·8h、综合指数 |
| **分析 · 比值** | PM₂.₅/PM₁₀、粗颗粒物占比、O₃/NO₂、SO₂/NO₂、CO/PM₂.₅ |

下方是**叠加**开关：风场、插值。

- **AQI 与污染物**按各自色阶着色，CO 用 mg/m³，其余浓度用 μg/m³。
- **结构比值**没有 AQI 等级语义，用的是线性比值色带，图例刻度跟浓度不是一套。
- **风场**给出风向风速的流线，配合浓度色场判断「是本地积累还是上游输送」。
- **插值**在实测点之间铺一层空间估算色场，帮助看趋势；关掉就只剩城市点。

## 四、城市点与插值色场不是一回事

这是分布图最容易被误读的地方，讲清楚两条：

1. **城市点是实测**。每个点对应一座城市的实测值，颜色来自它的 AQI 或浓度。
2. **大面积色块是插值**。色场由实测点按距离反比加权推算，用来让趋势可读。在站点稀疏的西部，插值的不确定度明显更大。

所以「图上我这片是橙色，但我所在城市读数是黄色」是正常的：色场是空间估算，城市读数是实测。要看准数字，点开城市，或去实时监测页。

## 五、从全国下钻到区县

- **全国视图**：一城一点，覆盖全国 389 座地级及以上城市（每一帧按当帧有效城市数着色）。
- **省份视图**：31 个省级区域按域内平均 AQI 着色，右侧同时排出省级榜单。
- **点开一个省**：地图换成省内城市逐时对比，右侧换成本省城市排行。
- **点开一个城市**：继续下钻到区县，同时可以打开城市弹窗，看它的六项污染物与实况气象。

两个视图共用同一套时间轴、分辨率与图层设置，切过去还是这个时次，不用重新选时间。

## 六、免费账号能看到哪些时次

- **当天**：可以看当前时次与当天已出的逐小时帧。
- **昨天**：可以看日粒度的那一帧（日聚合要等当天结束才出，所以昨天是日列表最后一帧）。
- **更早的时次**：按会员档位开放，档位越高可回放的时段越长。

## 七、点开一座城市会看到什么

城市弹窗给出这个位置在**当前时次**的全套读数：AQI 与等级、六项污染物浓度、首要污染物、天气现象、温度、湿度、风向风速、能见度、气压。

这也是分布图与实时监测页的衔接点：弹窗里读完，可以一键进到这座城市的历史曲线，把「此刻」接到「过程」上。
